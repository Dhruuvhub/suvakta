# Suvakta (FlowFest)

A React + Vite event landing page — teal brand palette derived from the Suvakta logo, bold outlines, and gradient strip accents.

## Color scheme

The palette is **logo-led and high-contrast**: a soft mist-teal page background, logo petroleum teal for structure and banners, bright seafoam CTAs, and deep teal-black outlines. White cards and labels pop clearly against the light base — same visual hierarchy as before, rebased on brand teal.
